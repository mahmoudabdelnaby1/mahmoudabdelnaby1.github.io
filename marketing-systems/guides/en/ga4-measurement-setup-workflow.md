# GA4 Measurement Setup Workflow

Plan a GA4 property, event map, and quality checks before relying on reports for decisions.

## When to use it
Use this workflow for a new GA4 implementation or a structured review of an existing measurement setup.

## What you need
Business questions; site or app events; consent requirements; GTM plan; conversion definitions; test environment.

## Workflow
1. Translate business questions into measurable events and parameters.
2. Document naming, parameter types, consent behavior, and exclusions.
3. Implement in a test environment and inspect event payloads.
4. Validate key events and deduplication against the originating action.
5. Record the owner, known gaps, and post-release monitoring plan.

## Practical output
An event dictionary, implementation checklist, and QA record.

## Scope and limits
A checklist cannot confirm live receipt. Verify in the target GA4 property and respect consent, privacy, and retention requirements.
