Set UTM Naming Rules Your Whole Team Can Follow

Create consistent campaign tags that remain readable across teams and reports.

Mahmoud Abdelnaby·2 min read·العربية

Uncontrolled spelling, capitalization and naming can fragment one campaign into many report rows.

Practical workflow

  1. Choose required parameters and allowed values.
  2. Use a shared campaign naming pattern.
  3. Assign a naming owner and preflight check.
  4. Document how to correct legacy tags safely.

Working template

source: _ / medium: / campaign: _ / content: / market-language rule: _ / owner: _.

Applied example

Use one agreed spelling for a platform and one stable campaign slug; put creative variation in utm_content, not utm_campaign.

Measure and review

Audit unknown values and report fragmentation monthly; preserve original links in records.

Guardrail

Never place names, email addresses or other personal data in query parameters.
