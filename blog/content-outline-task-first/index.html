Outline an Article Around the Reader’s Job

Order explanations so a reader can answer, decide, act and verify progress.

Mahmoud Abdelnaby·2 min read·العربية

A keyword-led outline can repeat definitions while postponing the answer readers need.

Practical workflow

  1. Write the task and answer-first summary.
  2. List prerequisite decisions and steps in order.
  3. Add examples where a mistake is likely.
  4. End with verification, limits and next resource.

Working template

Task: _ / answer: / prerequisites: _ / steps: / example: _ / success check: _ / limitation: ____.

Applied example

A guide to UTMs should show naming rules before a long history of campaign tagging.

Measure and review

Ask a reader to find the answer and perform the task using the outline.

Guardrail

Do not add FAQ headings that repeat the same answer without added utility.
