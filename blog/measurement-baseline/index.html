Record a Marketing Baseline Before Changing Campaigns

Capture the same definitions and sources that later comparisons will use.

Mahmoud Abdelnaby·6 min read·العربية

A baseline is a record of how a defined outcome was measured before a change. Without the same definitions and sources later, the comparison can describe two different systems rather than improvement.

Freeze the measurement contract

Before changing a campaign, page, or workflow, write down the outcome, event definition, source of truth, time window, market, segment, and known limitations. Save the report or export with a timestamp and note what else was changing: price, stock, season, staffing, tracking, or offer.

For a lead journey, a useful baseline may separate: landing sessions, contact clicks, messages received, qualified inquiries, appointments, and completed services. If the team can verify only the first two, say so. Do not label the click count “leads” to make the report look complete.

Choose a comparison that fits the decision

Use equivalent periods where possible and account for seasonality or operating-day differences. Keep the same event logic and filters. If tracking changed midway, mark the break and avoid calculating a seamless before/after percentage. A baseline is not a causal control group; it tells you what was observed before, not what would have happened without the change.

Make it reproducible

Record report link, filter set, event version, owner, and extraction date. After the intervention, rerun the same view and add a separate note for any changed definition. If data is incomplete, preserve the gap instead of backfilling estimates as observed fact.
