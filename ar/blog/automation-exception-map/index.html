محمود عبدالنبي·٧ دقائق للقراءة·English

يتحدد مسار الأتمتة بما يفعله عند المدخل الغريب كما يتحدد بما يفعله في الحالة المعتادة. إذا عالج كل حقل مفقود بافتراض واثق، فقد يوسع الأخطاء أسرع من العمل الصحيح.

ارسم الاستثناءات قبل ربط الأدوات

لكل خطوة سجّل المدخلات المتوقعة والنطاق الصالح والمسؤول. ثم حدد التصرف عند فقدان المدخل أو تكراره أو تقادمه أو تعارضه أو خروجه عن النطاق أو حساسيته. اختر نتيجة من أربع: متابعة ببديل آمن، سؤال المستخدم، إحالة إلى إنسان، أو إيقاف وتنبيه المسؤول.

مثال: توجيه استفسار حملة

  • غياب السوق ← اسأل عن البلد؛ لا تستنتجه من اللهجة أو عنوان الإنترنت.
  • خدمة خارج التغطية ← اشرح الحد أو أحل إلى بديل معتمد؛ لا تنشئ حجزًا.
  • إرسال مكرر ← اربطه بالحالة القائمة وأوقف المتابعة المكررة.
  • ادعاء غير مدعوم في النص ← سجله كقول العميل لا كحقيقة معتمدة عن المنتج.
  • انتهاء مهلة النظام ← أعد المحاولة ضمن حد محدد ثم نبّه مسؤولًا؛ لا تُسقط الاستفسار بصمت.

اجعل المسار البديل مرئيًا

سجل نوع الاستثناء ومصدره ونسخة المسار والإجراء وهل حُلّت الحالة. قلّل البيانات الشخصية في السجلات. أعطِ المستخدم طريقة لتصحيح المعلومة أو التواصل مع شخص. اختبر كل استثناء بحالات اصطناعية أو مجهّلة قبل تفعيل الإجراءات الخارجية.

راجع تكرار الاستثناءات والإنذارات الخاطئة بعد الإطلاق. إذا غلب مسار واحد، حسّن النموذج أو القواعد بدل تكديس تعليمات النموذج. أبقِ الإرسال والإنفاق والحذف وتغيير الصلاحيات خلف موافقة بشرية صريحة ما لم يوجد ضابط مستقل معتمد.

٣ — راجع قبل الاستخدام

طابق كل ادعاء بالمصدر. افصل الحقيقة عن المثال والفرضية، وافحص الخصوصية والاستثناءات. أعد أي خانة لا يدعمها دليل بصيغة «غير معروف»؛ لا تنشر المخرج ولا تنفذ إجراءً حيًا تلقائيًا.

القيمة: لكل خطوة سجّل المدخلات المتوقعة والنطاق الصالح والمسؤول. ابدأ بتحديد الحالة ومصدرها، ثم نفّذ خطوة واحدة قابلة للمراجعة. لا تعتبر المثال أو الفرضية نتيجة مؤكدة.
