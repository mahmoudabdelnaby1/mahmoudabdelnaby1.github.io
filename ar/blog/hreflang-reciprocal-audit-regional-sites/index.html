راجع hreflang بين الأسواق بخريطة ترابط لكل صفحة

قد تكون وسوم اللغة صحيحة في صفحة، بينما تتعطل مجموعة النسخ لأن الصفحة المقابلة لا تشير إليها، أو تستخدم رابطًا غير مكافئ، أو تعلن canonical إلى نسخة أخرى. راجع العلاقة بين الصفحات كرسم صغير: ما الروابط التي تمثل فعلًا المحتوى نفسه بلغات أو أسواق مختلفة؟ وهل تشير كل نسخة إلى بقية النسخ نفسها؟

توصي Google باستخدام عناوين منفصلة للنسخ اللغوية وتدعم وسوم hreflang لمساعدة البحث على اختيار النسخة المناسبة. تحتاج الإشارات إلى علاقة متبادلة: إذا أشارت الصفحة A إلى الصفحة B، يجب أن تعود B بالإشارة إلى A. رمز اللغة يستند إلى ISO 639-1، وقد يضاف رمز منطقة من ISO 3166-1 Alpha 2. رمز المنطقة وحده غير صالح، وبعض الرموز الشائعة مثل UK لا تستخدم كرمز البلد؛ استخدم الرمز الصحيح مثل en-GB. حدّد النسخ التي تؤدي المهمة نفسها

لا تربط صفحتين لمجرد أنهما تتحدثان عن المجال العام نفسه. يجب أن تكونا بديلين مفهومين للشخص بحسب اللغة أو السوق، وأن تتطابقا في الغرض الأساسي. قد تختلف الأسعار أو التوصيل أو الأمثلة المحلية، لكن صفحة منتج وصفحة فئة لا تصبحان بديلين لمجرد وجود المنتج نفسه.

ابدأ بقائمة الصفحات الأساسية في كل لغة، ثم اربط المتغيرات المؤكدة فقط. إذا لم توجد ترجمة، لا تخترع رابطًا أو توجه المستخدم إلى الصفحة الرئيسية لمجرد إكمال الوسم. يمكن ترك مجموعة غير مكتملة حيث تسمح إرشادات Google بذلك، مع توثيق سبب عدم وجود نسخة.

اجمع الإشارات من الصفحات المنشورة

اقرأ HTML المعروض بعد البناء، وليس قالب المصدر وحده. سجّل hreflang والـ canonical واللغة المرئية والعنوان والرابط النهائي والحالة HTTP لكل نسخة. انتبه إلى الروابط ذات المعاملات أو الشرط المائل أو النطاق المختلف التي تبدو متشابهة لكنها ليست الوجهة المنشورة المتوقعة.

تسمح Google بوضع الإشارات في HTML أو رؤوس HTTP أو sitemap؛ اختر طريقة يسهل صيانتها. الجمع بين الطرق الثلاث لا يعطي فائدة إضافية في البحث وقد يصعب صيانته. تأكد من أن كل نسخة تسرد نفسها والنسخ الأخرى نفسها، وأن الروابط كاملة باستخدام HTTPS عند انطباقه.

افحص canonical والتكافؤ قبل إصلاح الروابط

قارن الصفحة التي تعلن كنسخة مع الـ canonical الذي تفضله. إذا كان canonical يوجه إلى نسخة بلغة أخرى، فقد تتعارض الإشارات. لا تعدل canonical أو hreflang تلقائيًا لإزالة اختلاف لا تفهم سببه؛ تحقق من أن الصفحتين مستقلتان ومقصودتان للفهرسة وأن المحتوى الرئيسي بلغة النسخة.

راجع تغييرات العملة والشحن والخدمة. إذا كان اختلاف السوق جوهريًا، استخدم رمز لغة-منطقة صحيحًا عندما يناسب ذلك، ولا تعتبر hreflang إشارة لتغيير الأسعار أو تجربة البلد. اجعل اللغة مرئية وواضحة للقارئ؛ Google تحدد لغة الصفحة من المحتوى، وليس من HTML lang أو hreflang وحدهما.

أنشئ خريطة علاقات بدل قائمة روابط مبعثرة

سجل مجموعة البدائل نفسها لكل عضو. فشل الرجوع أو اختلاف المجموعة يكشفه الجدول بسرعة. إذا كانت الترجمة ناقصة أو غير مكافئة، أوقف الربط واطلب قرارًا تحريريًا بدل تحويل ذلك إلى إصلاح تقني.

سكريبت فيديو قصير: وسوم اللغة تحتاج رجوعًا

الخطاف: «صفحتك العربية تشير للإنجليزية، لكن هل الإنجليزية تشير للعربية؟»

القيمة: اعرض نسختين من الصفحة، وتحقق من أن كل واحدة تسرد نفسها والنسخة البديلة نفسها، ثم راجع canonical.

الخاتمة: «لا تربط إلا نسخًا تؤدي المهمة نفسها، وافحص HTML المنشور».

كاروسيل تعليمي: ستة فحوص لـhreflang

  1. الغلاف: راجع العلاقة بين الصفحات، لا الوسم وحده.
  2. هل النسختان بديلان حقيقيان للصفحة نفسها؟
  3. هل كل نسخة تشير إلى نفسها وبقية النسخ؟
  4. هل اللغة والبلد رموز صحيحة؟
  5. هل canonical متسق مع النسخة المقصودة؟
  6. هل فحصت الإشارات في HTML النهائي أو مصدرها المختار؟

سلسلة تجربة ميدانية: راجع مجموعة روابط بلغتين

1/ اختر مجموعة محدودة من الصفحات المتطابقة الغرض، وسجل النسخ المنشورة واللغة والسوق.

2/ اجمع hreflang وcanonical والحالة النهائية لكل صفحة بعد التحويلات.

3/ قارن قائمة البدائل ذهابًا وإيابًا، وحدد النسخة التي لا تعود أو تشير لصفحة غير مكافئة.

4/ راجع اختلاف المحتوى والغرض والعملة والشحن قبل تغيير القالب.

5/ أصلح مجموعة واحدة ثم افحص النسخ المنشورة. نجاح الوسم لا يثبت زيادة الزيارات أو اختيار Google لهذه النسخة.

حزمة مطالبات محايدة للأدوات: حلل خريطة النسخ

المطالبة 1 — استخراج الإشارات: «من HTML النهائي [ ]، استخرج hreflang والـ canonical والرابط النهائي واللغة الظاهرة. لا تفترض صحة الإشارات».

المطالبة 2 — التبادلية: «قارن مجموعات البدائل لكل عنوان. أظهر الصفحات التي ينقصها رابط رجوع أو لديها قائمة مختلفة، مع ذكر الروابط كما ظهرت».

المطالبة 3 — التكافؤ: «قارن هدف الصفحتين ومحتواهما الأساسي وسوقهما. صنفهما بديلين حقيقيين أو غير متكافئين أو يحتاجان قرارًا تحريريًا، ولا تفرض ربطًا تقنيًا».

ملف أمثلة: أوقف هذا: روابط بديلة غير مكافئة

أوقف: ربط كل صفحة عربية بالرئيسية الإنجليزية كي تكتمل الوسوم.

استخدم: اربط الصفحة ببديلها الحقيقي، واترك الصفحات دون نظير عند الحاجة.

أوقف: استخدام uk كرمز منطقة دون مراجعة معيار Google.

استخدم: حدد اللغة والمنطقة الصحيحتين بصيغة مدعومة مثل en-GB عندما تنطبق.

أوقف: إضافة hreflang في HTML وsitemap والقالب دون معرفة المصدر الفعلي.

استخدم: اختر مسارًا واحدًا يمكن فحصه وصيانته، ثم تحقق من النتيجة المنشورة.

الخطاف والقيمة والقالب: وثّق مجموعة بدائل واضحة

الخطاف: «هل الصفحات التي ربطتها بدائل حقيقية أم مجرد موضوع متقارب؟»

القيمة: خريطة متبادلة تربط الإشارات التقنية بهدف المحتوى وتكشف التعارض بين hreflang وcanonical قبل أن تتراكم الاستثناءات.

القالب: «المجموعة [ ]. الصفحة [URL]. البديل [URL]. اللغة/المنطقة [ ]. الغرض والتكافؤ [ ]. الحالة والوجهة النهائية [ ]. hreflang ذهابًا/إيابًا [ ]. canonical [ ]. المصدر التقني [HTML/HTTP/sitemap]. القرار [إصلاح/قرار تحريري/إبقاء] بسبب [الدليل].»
