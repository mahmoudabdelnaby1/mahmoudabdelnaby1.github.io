مراجعة تغييرات Meta Marketing API

استخدم قائمة تبدأ بالمصادر الرسمية لتقييم تغييرات API مقابل الحقول وسير العمل التي يستخدمها تكاملك فعليًا.

متى تستخدمه

استخدم سير العمل عند مراجعة إصدار Meta API أو تجهيز إصدار يعتمد على سلوك Marketing API.

ما الذي تحتاجه

سجل التغييرات الرسمي الحالي؛ إصدارات API المستخدمة؛ قائمة نقاط النهاية والحقول؛ حساب اختبار؛ مسؤول التكامل؛ خطة تراجع.

سير العمل

  1. اقرأ سجل التغييرات الرسمي الحالي وسجّل تاريخ نشره.
  2. ابحث في التكامل عن نقاط النهاية والحقول والصلاحيات والافتراضات المتأثرة.
  3. اربط كل تغيير بمسؤول وشدة وحالة اختبار وموعد.
  4. اختبر في بيئة غير إنتاجية وقارن البيانات المتوقعة.
  5. وثّق الإطلاق والمراقبة والبديل والتراجع قبل النشر.

المخرج العملي

سجل أثر الإصدار وقائمة ضمان إصدار مرتبطة بالوثائق الرسمية.

النطاق والحدود

لا تحدد هذه الصفحة إصدار API حاليًا ولا تسرد التغييرات الحالية. راجع وثائق Meta الرسمية قبل كل استخدام.
