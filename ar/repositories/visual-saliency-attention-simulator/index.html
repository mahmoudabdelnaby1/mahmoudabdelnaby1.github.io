صفحة تعريفية مستقلة بمستودع محاكي خرائط الانتباه البصري لصفحات الهبوط. توضّح ما الذي يحاول حله، ولمن يناسب، وما الملفات التي ستجدها قبل الانتقال إلى المصدر.

المشكلة التي يعالجها

يوضح التوثيق الأصلي نطاق المشكلة بهذا الوصف:

Build an open-source visual attention saliency generator in Python (visual_saliency.py): 1) Uses multi-scale luminance, color-opponent, and edge orientation gradients (Itti-Koch-Niebur model approximation) to calculate visual attention maps from landing page screenshots, 2) Overlays a smooth jet/turbo colormap heatmap onto the original image, 3) Computes a heuristic CTA prominence score (0-100) for comparative exploration, not a validated measure of conversion or gaze.

النطاق والقيود

  • Heuristic Scope: Saliency heatmaps represent algorithmic approximations of pre-attentive human vision (luminance, color contrast, edge orientation), not actual eye-tracking.
  • RTL Scanning Bias: Saliency models for Arabic interfaces must account for right-to-left scanning patterns that reverse traditional Western F-shaped gaze paths.
  • Above-the-Fold Viewport Constraints: Evaluates primary CTA visual pop against busy background imagery on mobile viewports (390px width).
