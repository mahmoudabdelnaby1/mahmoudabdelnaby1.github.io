دليل المستودع: مجموعة التحقق من الادعاءات التسويقية ومصادرها

صفحة تعريفية مستقلة بمستودع مجموعة التحقق من الادعاءات التسويقية ومصادرها. توضّح ما الذي يحاول حله، ولمن يناسب، وما الملفات التي ستجدها قبل الانتقال إلى المصدر.

المشكلة التي يعالجها

يوضح التوثيق الأصلي نطاق المشكلة بهذا الوصف:

Build an open-source marketing claim verification system: 1) Agent Skill (SKILL.md) that extracts factual assertions, percentages, pricing claims, and competitive comparisons from marketing copy, 2) Python CLI script (extract_claims.py) that surfaces unverified numerical claims for human review, 3) 20-point legal and regulatory compliance checklist for consumer claims.

لمن صُمم؟

الجمهور المحدد في README: BOTH operating in high-growth e-commerce, digital publishing, and direct-response marketing across Saudi Arabia, UAE, and Egypt.

طريقة مراجعته واستخدامه

  1. ابدأ بقراءة README وتأكد أن المشكلة المذكورة تطابق احتياجك الفعلي.
  2. افحص الملفات المذكورة أعلاه؛ أسماء الملفات توضح مكان البيانات والأدوات والقوالب والاختبارات.
  3. اتبع Quick Start الموجود في README، وتحقق من المتطلبات قبل تشغيل أي أمر.
  4. قارن المخرجات بعينة موثقة، وراجع القيود قبل استخدامها في قرار أو عمل عميل.

أمثلة أوامر البدء من README: python -m unittest discover -s tests · python src/extract_claims.py --help

النطاق والقيود

  • Auditable Claim Evidence: Replaces vague marketing superlatives with verifiable factual assertions and documented performance metrics.
  • Saudi Statutory Anti-Misleading Rules: Verifies compliance with Saudi Ministry of Commerce prohibitions against false advertising.
  • Testimonial Attribution Standards: Mandates documented user consent and proof of real customer status before publishing testimonials.

هذه الصفحة تلخص التوثيق المتاح ولا تثبت أداءً أو نتيجة تجارية. تحقق من صلاحية البيانات والمتطلبات قبل الاستخدام.
