دليل المستودع: بروتوكول قياس ظهور العلامة والاستشهاد بها في محركات البحث التوليدية (GEO)

صفحة تعريفية مستقلة بمستودع بروتوكول قياس ظهور العلامة والاستشهاد بها في محركات البحث التوليدية (GEO). توضّح ما الذي يحاول حله، ولمن يناسب، وما الملفات التي ستجدها قبل الانتقال إلى المصدر.

المشكلة التي يعالجها

يوضح التوثيق الأصلي نطاق المشكلة بهذا الوصف:

Build an exhaustive GEO citation audit protocol repository containing: 1) Benchmark query matrix (50 Arabic and 50 English test queries for e-commerce, B2B, and travel), 2) Citation scoring rubric (Direct Link, Named Entity Mention, Sentiment Polarity, Hallucination Risk), 3) Markdown evaluation templates, 4) Python CLI script (geo_scorer.py) that calculates citation density from saved LLM output text files.

لمن صُمم؟

الجمهور المحدد في README: PRO operating in high-growth e-commerce, digital publishing, and direct-response marketing across Saudi Arabia, UAE, and Egypt.

طريقة مراجعته واستخدامه

  1. ابدأ بقراءة README وتأكد أن المشكلة المذكورة تطابق احتياجك الفعلي.
  2. افحص الملفات المذكورة أعلاه؛ أسماء الملفات توضح مكان البيانات والأدوات والقوالب والاختبارات.
  3. اتبع Quick Start الموجود في README، وتحقق من المتطلبات قبل تشغيل أي أمر.
  4. قارن المخرجات بعينة موثقة، وراجع القيود قبل استخدامها في قرار أو عمل عميل.

أمثلة أوامر البدء من README: python -m unittest discover -s tests · python tools/geo_scorer.py --help

النطاق والقيود

  • LLM Probabilistic Output: Generative engine optimization metrics represent observational heuristic frequencies of LLM citations across temperature settings, not algorithmic guarantees.
  • Multi-Engine Volatility: Citation presence varies between Perplexity, ChatGPT Search, and Google Gemini depending on model versions and search index freshing.
  • Neutral Attribution Auditing: Brand mentions are scored based on contextual prominence, authoritative source linking, and factual entity clustering.

هذه الصفحة تلخص التوثيق المتاح ولا تثبت أداءً أو نتيجة تجارية. تحقق من صلاحية البيانات والمتطلبات قبل الاستخدام.
