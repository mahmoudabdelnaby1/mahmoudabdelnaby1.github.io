دليل المستودع: بطاقة تقييم جودة مخرجات التسويق ومراجعة طلبات الدمج

صفحة تعريفية مستقلة بمستودع بطاقة تقييم جودة مخرجات التسويق ومراجعة طلبات الدمج. توضّح ما الذي يحاول حله، ولمن يناسب، وما الملفات التي ستجدها قبل الانتقال إلى المصدر.

المشكلة التي يعالجها

يوضح التوثيق الأصلي نطاق المشكلة بهذا الوصف:

Build an open-source Marketing Quality Gate and Peer Review system: 1) 25-point weighted QA scorecard covering Copywriting, Visual Design, Technical Tracking/UTMs, and Legal Compliance, 2) Ready-to-use GitHub Pull Request templates (.github/PULL_REQUEST_TEMPLATE/marketing_release.md), 3) Pre-flight campaign launch sign-off matrix, 4) Incident post-mortem template for marketing failures.

لمن صُمم؟

الجمهور المحدد في README: PRO operating in high-growth e-commerce, digital publishing, and direct-response marketing across Saudi Arabia, UAE, and Egypt.

طريقة مراجعته واستخدامه

  1. ابدأ بقراءة README وتأكد أن المشكلة المذكورة تطابق احتياجك الفعلي.
  2. افحص الملفات المذكورة أعلاه؛ أسماء الملفات توضح مكان البيانات والأدوات والقوالب والاختبارات.
  3. اتبع Quick Start الموجود في README، وتحقق من المتطلبات قبل تشغيل أي أمر.
  4. قارن المخرجات بعينة موثقة، وراجع القيود قبل استخدامها في قرار أو عمل عميل.

خطوة البدء: افتح README وراجع قسم الاستخدام والمتطلبات.

النطاق والقيود

  • Multi-Point Review Scorecard: Evaluates deliverables across 5 dimensions (Brief Alignment, Factual Accuracy, Technical Formatting, Brand Tone, Proofing).
  • Peer Review Pull Request Model: Adapts software pull-request review culture into marketing creative and strategic deliverables.
  • Zero Defect Threshold: Mandates passing all quality gate checks before deliverables are exported or presented to clients.

هذه الصفحة تلخص التوثيق المتاح ولا تثبت أداءً أو نتيجة تجارية. تحقق من صلاحية البيانات والمتطلبات قبل الاستخدام.
