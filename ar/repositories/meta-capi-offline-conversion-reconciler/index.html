دليل المستودع: Meta CAPI Offline Conversion Reconciliation Utility

صفحة تعريفية مستقلة بمستودع Meta CAPI Offline Conversion Reconciliation Utility. توضّح ما الذي يحاول حله، ولمن يناسب، وما الملفات التي ستجدها قبل الانتقال إلى المصدر.

المشكلة التي يعالجها

يوضح التوثيق الأصلي نطاق المشكلة بهذا الوصف:

Develop a pure Python CLI utility (capi_reconciler.py) for formatting Meta CAPI offline events: 1) Normalizes Egyptian (+20) and GCC (+966, +971, +965, etc.) phone numbers to strict E.164 standards, handling missing leading zeroes, 2) Performs lowercase SHA256 hashing on emails, names, and phone numbers, 3) Formats Unix timestamps, 4) Generates a pre-flight validation report showing estimated Event Match Quality.

النطاق والقيود

  • Event Deduplication (event_id): Requires identical event_id and event_name on both browser pixel and server CAPI payloads within 48-hour deduplication window.
  • Customer Information Parameters: Hashes PII (email, phone, first/last name) with SHA-256 before transmission to maximize Event Quality Match score.
  • Timezone Normalization: Offline CRM delivery events must be converted to UTC Unix timestamps to match Meta ad auction attribution windows.
