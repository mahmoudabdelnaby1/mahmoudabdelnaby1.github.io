دليل المستودع: قاموس أحداث التجارة الإلكترونية في GA4 بالشرق الأوسط ومخطط BigQuery

صفحة تعريفية مستقلة بمستودع قاموس أحداث التجارة الإلكترونية في GA4 بالشرق الأوسط ومخطط BigQuery. توضّح ما الذي يحاول حله، ولمن يناسب، وما الملفات التي ستجدها قبل الانتقال إلى المصدر.

المشكلة التي يعالجها

يوضح التوثيق الأصلي نطاق المشكلة بهذا الوصف:

Build an exhaustive GA4 e-commerce taxonomy and BigQuery SQL schema pack for MENA: 1) Extended e-commerce event taxonomy specification (including cod_placed, cod_verified, bnpl_selected, delivery_completed), 2) BigQuery SQL query templates that require adaptation and validation against your GA4 export schema (unnesting events, customer lifetime value, blended attribution), 3) GTM Web and Server-Side container examples that require review and configuration before import.

النطاق والقيود

  • Required E-Commerce Parameter Consistency: Enforces official items array schemas with item_id, item_name, price, and item_category.
  • Currency Normalization: Multi-currency regional transactions (SAR, AED, EGP, USD) must be explicitly passed at event level to prevent conversion distortion.
  • BigQuery Partitioning: Daily event export partitions require integer transaction timestamps (event_timestamp) for performant querying.
