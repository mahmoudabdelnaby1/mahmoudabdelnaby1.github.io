النطاق والقيود

  • Sub-Millisecond Edge Latency: Cloudflare Workers edge rules must execute within tight CPU limits (<10ms) to prevent TTFB degradation.
  • Canonical Header Precedence: HTTP 'Link: <url>; rel="canonical"' headers take precedence over conflicting in-HTML meta tags across search engines.
  • Security Header Compatibility: Strict CSP and HSTS headers must not block legitimate third-party analytics (GA4, CAPI) or regional payment gateways.
