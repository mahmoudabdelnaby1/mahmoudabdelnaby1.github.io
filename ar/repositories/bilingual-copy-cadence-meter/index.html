دليل المستودع: مقياس إيقاع وقوة النصوص ثنائية اللغة عربي-إنجليزي

صفحة تعريفية مستقلة بمستودع مقياس إيقاع وقوة النصوص ثنائية اللغة عربي-إنجليزي. توضّح ما الذي يحاول حله، ولمن يناسب، وما الملفات التي ستجدها قبل الانتقال إلى المصدر.

المشكلة التي يعالجها

يوضح التوثيق الأصلي نطاق المشكلة بهذا الوصف:

Build an open-source copywriting rhythm and cadence analyzer in Python (cadence_meter.py): 1) Analyzes sentence word-length variance (calculating cadence score and visual rhythm wave), 2) Detects configured passive or filler phrases in Arabic and English, 3) Suggests direct, punchy alternatives, 4) Outputs an interactive HTML visual report highlighting monotonous paragraphs.

لمن صُمم؟

الجمهور المحدد في README: BOTH operating in high-growth e-commerce, digital publishing, and direct-response marketing across Saudi Arabia, UAE, and Egypt.

طريقة مراجعته واستخدامه

  1. ابدأ بقراءة README وتأكد أن المشكلة المذكورة تطابق احتياجك الفعلي.
  2. افحص الملفات المذكورة أعلاه؛ أسماء الملفات توضح مكان البيانات والأدوات والقوالب والاختبارات.
  3. اتبع Quick Start الموجود في README، وتحقق من المتطلبات قبل تشغيل أي أمر.
  4. قارن المخرجات بعينة موثقة، وراجع القيود قبل استخدامها في قرار أو عمل عميل.

أمثلة أوامر البدء من README: python -m unittest discover -s tests · python src/cadence_meter.py --help

النطاق والقيود

  • Syllable & Word Length Ratios: Measures reading cadence in Arabic and English, calculating syllables-per-word and sentence punchiness.
  • Arabic Morphological Complexity: Distinguishes between heavy classical agglutinative words and punchy modern colloquial advertising copy.
  • CTA Readability Scoring: Flags wordy, passive CTAs and recommends concise, action-oriented regional verbs.

هذه الصفحة تلخص التوثيق المتاح ولا تثبت أداءً أو نتيجة تجارية. تحقق من صلاحية البيانات والمتطلبات قبل الاستخدام.
