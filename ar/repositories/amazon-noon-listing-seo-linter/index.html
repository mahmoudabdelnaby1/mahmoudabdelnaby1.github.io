دليل المستودع: مدقق SEO وتوافق الكلمات المفتاحية لقوائم Amazon وNoon الإقليمية

صفحة تعريفية مستقلة بمستودع مدقق SEO وتوافق الكلمات المفتاحية لقوائم Amazon وNoon الإقليمية. توضّح ما الذي يحاول حله، ولمن يناسب، وما الملفات التي ستجدها قبل الانتقال إلى المصدر.

المشكلة التي يعالجها

يوضح التوثيق الأصلي نطاق المشكلة بهذا الوصف:

Build an open-source marketplace listing optimization and linting CLI (marketplace_linter.py): 1) Validates title length (200 chars), bullet point count (5 bullets, 150-250 chars), and backend search terms (250 bytes limit, UTF-8 aware for Arabic characters), 2) Detects 100+ prohibited promotional terms, 3) Compares listing text against top competitor keyword lists to output a keyword coverage gap score.

النطاق والقيود

  • Backend Search Terms Limits: Enforces strict byte limits (249 bytes on Amazon.sa, 250 characters on Noon) without repeating words already in the title.
  • Bilingual Keyword Parity: Ensures high-volume Arabic search terms are present alongside English brand names in titles, bullet points, and A+ content.
  • Prohibited Promotional Phrases: Screens text to prevent terms like 'Best Seller', 'Free Shipping', or warranty claims that trigger listing suppression.

هذه الصفحة تلخص التوثيق المتاح ولا تثبت أداءً أو نتيجة تجارية. تحقق من صلاحية البيانات والمتطلبات قبل الاستخدام.
