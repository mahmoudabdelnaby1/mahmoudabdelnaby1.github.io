دليل المستودع: أداة رسم قوة الروابط الداخلية ورصد الصفحات اليتيمة

صفحة تعريفية مستقلة بمستودع أداة رسم قوة الروابط الداخلية ورصد الصفحات اليتيمة. توضّح ما الذي يحاول حله، ولمن يناسب، وما الملفات التي ستجدها قبل الانتقال إلى المصدر.

المشكلة التي يعالجها

يوضح التوثيق الأصلي نطاق المشكلة بهذا الوصف:

Create a standalone Python CLI tool that parses standard crawl export CSVs (Screaming Frog or Sitebulb format), builds a directed graph of internal links, computes internal PageRank using iterative power-iteration, identifies orphan pages (0 inlinks), and generates an interactive, standalone HTML topology visualization report.

لمن صُمم؟

الجمهور المحدد في README: PRO operating in high-growth e-commerce, digital publishing, and direct-response marketing across Saudi Arabia, UAE, and Egypt.

طريقة مراجعته واستخدامه

  1. ابدأ بقراءة README وتأكد أن المشكلة المذكورة تطابق احتياجك الفعلي.
  2. افحص الملفات المذكورة أعلاه؛ أسماء الملفات توضح مكان البيانات والأدوات والقوالب والاختبارات.
  3. اتبع Quick Start الموجود في README، وتحقق من المتطلبات قبل تشغيل أي أمر.
  4. قارن المخرجات بعينة موثقة، وراجع القيود قبل استخدامها في قرار أو عمل عميل.

أمثلة أوامر البدء من README: python -m unittest discover -s tests · python src/pagerank_graph.py --help

النطاق والقيود

  • Graph Traversal Scale: Large enterprise e-commerce catalogs (>50,000 URLs) require directed graph adjacency matrices to compute PageRank without memory exhaustion.
  • Canonical & Noindex Filters: Orphan page radar must distinguish between intentionally hidden landing pages and accidental orphans missing internal links.
  • Crawl Depth Limits: Search bots prioritize pages within 3 to 4 click depths from the root domain.

هذه الصفحة تلخص التوثيق المتاح ولا تثبت أداءً أو نتيجة تجارية. تحقق من صلاحية البيانات والمتطلبات قبل الاستخدام.
