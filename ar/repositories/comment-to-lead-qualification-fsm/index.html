دليل المستودع: مواصفات آلة حالات لتأهيل التعليقات الواردة إلى عملاء محتملين

صفحة تعريفية مستقلة بمستودع مواصفات آلة حالات لتأهيل التعليقات الواردة إلى عملاء محتملين. توضّح ما الذي يحاول حله، ولمن يناسب، وما الملفات التي ستجدها قبل الانتقال إلى المصدر.

المشكلة التي يعالجها

يوضح التوثيق الأصلي نطاق المشكلة بهذا الوصف:

Build an open-source Finite State Machine qualification architecture for social commerce: 1) Mermaid FSM state diagram modeling transition states (Comment_Detected -> Intent_Classified -> Soft_DM_Triggered -> Needs_Human_Handoff -> Lead_Qualified), 2) Python state machine simulation script (fsm_simulator.py) validating edge cases, 3) Anti-ban rate limiting and human-handoff triggers.

لمن صُمم؟

الجمهور المحدد في README: PRO operating in high-growth e-commerce, digital publishing, and direct-response marketing across Saudi Arabia, UAE, and Egypt.

طريقة مراجعته واستخدامه

  1. ابدأ بقراءة README وتأكد أن المشكلة المذكورة تطابق احتياجك الفعلي.
  2. افحص الملفات المذكورة أعلاه؛ أسماء الملفات توضح مكان البيانات والأدوات والقوالب والاختبارات.
  3. اتبع Quick Start الموجود في README، وتحقق من المتطلبات قبل تشغيل أي أمر.
  4. قارن المخرجات بعينة موثقة، وراجع القيود قبل استخدامها في قرار أو عمل عميل.

أمثلة أوامر البدء من README: python -m unittest discover -s tests · python src/fsm_engine.py --help

النطاق والقيود

  • Deterministic State Transitions: Implements a Finite State Machine tracking comment lead lifecycle (Unreviewed -> Scored -> DM Initiated -> Qualified -> CRM Synced).
  • Platform Automation Rules: Adheres to Meta and Instagram API rate limits and messaging policies regarding automated direct messaging.
  • Sentiment & Keyword Routing: Prioritizes commercial intent keywords ('السعر', 'التوصيل') while deprioritizing spam and negative customer service complaints.

هذه الصفحة تلخص التوثيق المتاح ولا تثبت أداءً أو نتيجة تجارية. تحقق من صلاحية البيانات والمتطلبات قبل الاستخدام.
