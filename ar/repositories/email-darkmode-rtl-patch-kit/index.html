النطاق والقيود

  • Inverted Contrast Safeguards: Prevents dark-mode email clients (Apple Mail, Outlook) from inverting dark brand logos into invisible dark backgrounds.
  • RTL Table Alignment: Employs 'dir="rtl"' on outer tables and wraps to prevent nested text containers from flipping incorrectly across desktop Outlook engines.
  • prefers-color-scheme Media Queries: Injects targeted CSS media queries to explicitly control custom dark theme colors rather than relying on browser auto-inversion.

هذه الصفحة تلخص التوثيق المتاح ولا تثبت أداءً أو نتيجة تجارية. تحقق من صلاحية البيانات والمتطلبات قبل الاستخدام.
