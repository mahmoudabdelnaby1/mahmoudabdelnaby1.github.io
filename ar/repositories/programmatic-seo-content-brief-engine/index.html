صفحة تعريفية مستقلة بمستودع محرك إعداد موجزات محتوى SEO البرمجي للأسواق العربية. توضّح ما الذي يحاول حله، ولمن يناسب، وما الملفات التي ستجدها قبل الانتقال إلى المصدر.

المشكلة التي يعالجها

يوضح التوثيق الأصلي نطاق المشكلة بهذا الوصف:

Create an Agent Skill and toolkit for generating high-quality programmatic SEO content briefs in Arabic: 1) SKILL.md specifying entity density, local proof points, and heading hierarchy rules, 2) Anti-thin-content validation checklist, 3) Python merger script that converts structured CSV data into comprehensive markdown briefs, 4) Two complete worked examples (Real Estate Cairo & Services Riyadh).

طريقة مراجعته واستخدامه

  1. ابدأ بقراءة README وتأكد أن المشكلة المذكورة تطابق احتياجك الفعلي.
  2. افحص الملفات المذكورة أعلاه؛ أسماء الملفات توضح مكان البيانات والأدوات والقوالب والاختبارات.
  3. اتبع Quick Start الموجود في README، وتحقق من المتطلبات قبل تشغيل أي أمر.
  4. قارن المخرجات بعينة موثقة، وراجع القيود قبل استخدامها في قرار أو عمل عميل.

أمثلة أوامر البدء من README: python -m unittest discover -s tests · python scripts/generate_briefs.py --help

النطاق والقيود

  • Spam Policy Adherence: Content briefs must mandate unique localized data points per page to avoid Google scaled content abuse penalties.
  • Template Fatigue Mitigation: Dynamic variables must support randomized semantic syntactic variations across city/industry landing pages.
  • Structured Data Automation: Each programmatic page brief includes automated Schema.org LocalBusiness or Service JSON-LD specifications.

هذه الصفحة تلخص التوثيق المتاح ولا تثبت أداءً أو نتيجة تجارية. تحقق من صلاحية البيانات والمتطلبات قبل الاستخدام.
