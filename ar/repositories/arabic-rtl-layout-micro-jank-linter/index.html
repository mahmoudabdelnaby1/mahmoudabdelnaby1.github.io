دليل المستودع: مدقق اهتزاز التخطيط والانعكاس في واجهات RTL العربية

صفحة تعريفية مستقلة بمستودع مدقق اهتزاز التخطيط والانعكاس في واجهات RTL العربية. توضّح ما الذي يحاول حله، ولمن يناسب، وما الملفات التي ستجدها قبل الانتقال إلى المصدر.

المشكلة التي يعالجها

يوضح التوثيق الأصلي نطاق المشكلة بهذا الوصف:

Create an automated RTL design quality assurance toolkit: 1) Python scanner (rtl_linter.py) auditing CSS and HTML files for non-logical properties (margin-left vs margin-inline-start), hardcoded left-aligned icons, missing dir attributes, and unisolated bidirectional text tags (<bdi>), 2) 35-point visual RTL inspection checklist, 3) Modern CSS logical property migration guide.

طريقة مراجعته واستخدامه

  1. ابدأ بقراءة README وتأكد أن المشكلة المذكورة تطابق احتياجك الفعلي.
  2. افحص الملفات المذكورة أعلاه؛ أسماء الملفات توضح مكان البيانات والأدوات والقوالب والاختبارات.
  3. اتبع Quick Start الموجود في README، وتحقق من المتطلبات قبل تشغيل أي أمر.
  4. قارن المخرجات بعينة موثقة، وراجع القيود قبل استخدامها في قرار أو عمل عميل.

أمثلة أوامر البدء من README: python -m unittest discover -s tests · python src/rtl_linter.py --help

النطاق والقيود

  • CSS Logical Properties: Audits CSS stylesheets to ensure 'margin-inline-start' and 'inset-inline' replace legacy directional 'margin-left' and 'left' properties.
  • Icon Mirroring Directionality: Verifies that directional icons (arrows, back buttons, progress bars) mirror in RTL while non-directional icons (clocks, checkmarks) remain static.
  • Cumulative Layout Shift (CLS): Prevents layout jumps caused by late font swap or directional flips by enforcing RTL directionality on root <html> tag.

هذه الصفحة تلخص التوثيق المتاح ولا تثبت أداءً أو نتيجة تجارية. تحقق من صلاحية البيانات والمتطلبات قبل الاستخدام.
