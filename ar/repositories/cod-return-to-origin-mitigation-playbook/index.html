دليل المستودع: دليل الحد من مرتجعات الدفع عند الاستلام وعودة الشحن للمصدر

صفحة تعريفية مستقلة بمستودع دليل الحد من مرتجعات الدفع عند الاستلام وعودة الشحن للمصدر. توضّح ما الذي يحاول حله، ولمن يناسب، وما الملفات التي ستجدها قبل الانتقال إلى المصدر.

المشكلة التي يعالجها

يوضح التوثيق الأصلي نطاق المشكلة بهذا الوصف:

Build an open-source COD Return-to-Origin (RTO) mitigation toolkit for MENA: 1) operational playbook (Pre-Purchase Friction, WhatsApp 1-Click Confirmation, Prepaid Incentive Surcharges, Courier SLA Tracking, Blacklist Governance), 2) WhatsApp automated confirmation message templates (Arabic and English), 3) Python risk scoring script (rto_risk_scorer.py), 4) Courier handover reconciliation sheet.

لمن صُمم؟

الجمهور المحدد في README: BOTH operating in high-growth e-commerce, digital publishing, and direct-response marketing across Saudi Arabia, UAE, and Egypt.

طريقة مراجعته واستخدامه

  1. ابدأ بقراءة README وتأكد أن المشكلة المذكورة تطابق احتياجك الفعلي.
  2. افحص الملفات المذكورة أعلاه؛ أسماء الملفات توضح مكان البيانات والأدوات والقوالب والاختبارات.
  3. اتبع Quick Start الموجود في README، وتحقق من المتطلبات قبل تشغيل أي أمر.
  4. قارن المخرجات بعينة موثقة، وراجع القيود قبل استخدامها في قرار أو عمل عميل.

أمثلة أوامر البدء من README: python -m unittest discover -s tests · python src/rto_risk_scorer.py --help

النطاق والقيود

  • Multi-Pillar Risk Scoring: Calculates RTO probability based on address completeness, previous order refusal history, and city delivery performance.
  • Pre-Purchase Friction Rules: Offers optional confirmation and incentive ideas to evaluate against customer experience, local rules, and account data.
  • Courier SLA Handover Tracking: Tracks last-mile courier attempts, requiring automated WhatsApp intervention upon the first failed delivery attempt.

هذه الصفحة تلخص التوثيق المتاح ولا تثبت أداءً أو نتيجة تجارية. تحقق من صلاحية البيانات والمتطلبات قبل الاستخدام.
