دليل المستودع: Google Search Console Query Cannibalization Radar

صفحة تعريفية مستقلة بمستودع Google Search Console Query Cannibalization Radar. توضّح ما الذي يحاول حله، ولمن يناسب، وما الملفات التي ستجدها قبل الانتقال إلى المصدر.

المشكلة التي يعالجها

يوضح التوثيق الأصلي نطاق المشكلة بهذا الوصف:

Develop a pure Python CLI script (cannibalization_radar.py) that analyzes GSC performance exports (Query + Page + Clicks + Impressions + Position). It calculates the URL conflict score for each query, identifies SERP flapping pairs, outputs an interactive HTML report with severity color-coding, and provides a clear Markdown resolution playbook.

النطاق والقيود

  • Data Thresholding & API Limits: Google Search Console Search Analytics API limits exports to 25,000 rows per query request; pagination required for enterprise sites.
  • Intent Differentiation: Two URLs ranking for the same keyword is only true cannibalization if neither URL converts or achieves top 3 ranking.
  • Timeframe Smoothing: Audits require at least a 28-day window to distinguish temporary algorithmic A/B testing from chronic page conflict.
