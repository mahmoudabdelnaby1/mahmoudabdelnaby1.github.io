02COMMERCE ECONOMICS

E-commerce Unit Economics

Use it when
You need to estimate what remains from an order after fulfilment, payment, advertising, delivery outcomes, and returns.

What it includes
A blank input template and formula framework for contribution per order and break-even acquisition cost. It is not a pre-built spreadsheet calculator.

FROM INPUTS TO A DECISION

How to use a playbook

Choose for the decision you need to make, not just by the tool name.

  1. 01

    Name the decision

    Write the question you need answered and the decision the output should support.

  2. 02

    Bring real inputs

    Use current store, offer, market, and account data; record where it came from and when.

  3. 03

    Check assumptions

    Verify changing details in official documentation and involve a qualified reviewer when needed.

  4. 04

    Measure the result

    Compare with an appropriate baseline before attributing an outcome to the change.

CLEAR ANSWERS BEFORE YOU START

Questions people ask

Is this an AI platform?

No. This is a set of reusable written workflows and templates. It does not host or run AI models.

Is the e-commerce worksheet a ready-made calculator?

No. It is a blank input template and formula framework. Add your own figures, calculate, and review before making financial decisions.

Does the advertising review approve an ad legally?

No. It organizes a human review; it does not replace a regulator or qualified local counsel.

Do the playbooks guarantee better campaign results?

No. Outcomes depend on the market, offer, execution, and measurement. Treat examples as hypotheses and measure actual results.
