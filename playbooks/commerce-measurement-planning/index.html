When to use it

You are mapping or diagnosing browser and server-side commerce events across a storefront and ad platforms.

02

Prepare these inputs

The real data layer, event names, consent state, event IDs, timestamps, currency, order lifecycle, and platform setup.

03

A practical workflow

  1. 01

    Map each commerce event and its required fields.

  2. 02

    Check consent, event IDs, timestamps and deduplication across systems.

  3. 03

    Test platform receipts and reconcile them with backend orders.

04

What the toolkit contains

Event-mapping schemas, implementation and deduplication checklists, platform notes, and a blank evidence and reconciliation report.

05

Review boundaries

Test each platform and compare with backend orders. Server-side tracking does not guarantee restored signals or attribution.
