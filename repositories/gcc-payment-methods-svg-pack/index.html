GCC Localized Payment Method & Digital Wallet Vector Asset Pack

Stop using blurry payment logos. Pixel-perfect SVG vector icons for Mada, Knet, Benefit, Fawry, Instapay, Tabby, and Tamara in light and dark mode.

Problem it addresses

Build an open-source SVG vector asset repository for Middle Eastern payment methods: 1) Pixel-perfect, minified SVG files for Mada, Knet, Benefit (Bahrain), Fawry (Egypt), Instapay (Egypt), Meeza (Egypt), Tabby, Tamara, Apple Pay, Google Pay, STC Pay, and Cash on Delivery, 2) Light and dark mode variations, 3) Responsive HTML/CSS badge strip snippets, 4) Official brand usage rules (clear space, aspect ratio).
