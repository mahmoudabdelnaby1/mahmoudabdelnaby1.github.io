Meta Ad Creative Fatigue Velocity Radar

Detect ad creative fatigue before your CPA spikes. Analyze Meta Ads CSV exports locally with zero API tokens or credentials.

Problem it addresses

Develop a pure Python CLI (fatigue_radar.py) that ingests daily Meta Ads performance CSVs (Date, Ad ID, Impressions, Reach, Frequency, Spend, Clicks, Conversions). Calculates 3-day and 7-day rolling CTR and CPA slopes, flags ads entering the 'Fatigue Danger Zone', outputs an interactive HTML radar dashboard with visual status badges, and generates a rotation priority list.

Who it is for

PRO operating in high-growth e-commerce, digital publishing, and direct-response marketing across Saudi Arabia, UAE, and Egypt.

Scope and limitations

  • Audience Saturation Dynamics: Ad fatigue is measured via First-Time Impression Ratio (FTIR) and frequency acceleration curves, not static CTR drops.
  • API Rate Limiting: Meta Marketing API queries must implement exponential backoff when fetching granular daily ad-level insights.
  • Budget-Dependent Decay: Small daily budgets (<$50/ad set) exhibit slower decay curves than scaled ASC campaigns with rapid frequency buildup.
