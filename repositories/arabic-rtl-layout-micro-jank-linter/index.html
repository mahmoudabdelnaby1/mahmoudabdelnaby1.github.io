Arabic RTL Layout Micro-Jank & Mirroring Linter

Catch embarrassing RTL mirroring bugs, flipped arrows, and broken text layouts before your Arabic website launches.

Problem it addresses

Create an automated RTL design quality assurance toolkit: 1) Python scanner (rtl_linter.py) auditing CSS and HTML files for non-logical properties (margin-left vs margin-inline-start), hardcoded left-aligned icons, missing dir attributes, and unisolated bidirectional text tags (<bdi>), 2) 35-point visual RTL inspection checklist, 3) Modern CSS logical property migration guide.

Who it is for

BOTH operating in high-growth e-commerce, digital publishing, and direct-response marketing across Saudi Arabia, UAE, and Egypt.

Scope and limitations

  • CSS Logical Properties: Audits CSS stylesheets to ensure 'margin-inline-start' and 'inset-inline' replace legacy directional 'margin-left' and 'left' properties.
  • Icon Mirroring Directionality: Verifies that directional icons (arrows, back buttons, progress bars) mirror in RTL while non-directional icons (clocks, checkmarks) remain static.
  • Cumulative Layout Shift (CLS): Prevents layout jumps caused by late font swap or directional flips by enforcing RTL directionality on root <html> tag.
