5. Epistemic Labeling: Facts vs. Assumptions vs. Estimates vs. Recommendations

To prevent hallucinated confidence, prefix or tag all material statements in the output using this 4-tier protocol:

  • [FACT - Sourced]: Directly observed in user-provided exports, verified URLs, or official platform documentation (include exact citation/link and date).
  • [ASSUMPTION - Unverified]: Reasonable contextual premise adopted because primary data was not supplied (must be confirmed by the user before live spend or code cutover).
  • [ESTIMATE - Modeled Range]: Directional projection or scenario calculation derived from explicit formulas (always show the formula and low/base/high range; never present as guaranteed outcome).
  • [RECOMMENDATION - Actionable Next Step]: Concrete prioritized action with clear owner, prerequisite check, and rollback path.
